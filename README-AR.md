# Appigo — مشروع موقع الألعاب الثابت (Cloudflare Pages)

هذا المجلد يحتوي على النسخة الكاملة والمنظمة لمشروع **Appigo** (`appigo.site`) جاهزة للرفع على **GitHub** ثم النشر عبر **Cloudflare Pages**.

## محتويات المجلد
- `index.html`: الصفحة الرئيسية للموقع مع البحث والتصنيفات وبيانات Schema.
- `game/index.html`: صفحة عرض اللعبة والمشغّل (iframe) والدليل والأسئلة الشائعة.
- `css/style.css`: ملف التصميم المتجاوب الكامل.
- `js/app.js` و `js/game.js`: ملفات تشغيل البحث، التصنيفات، وعرض تفاصيل كل لعبة ديناميكياً.
- `data/games.json`: قاعدة بيانات تضم **25 لعبة** كاملة بالوصف الإنجليزي الحصري وطريقة اللعب والنصائح والأسئلة الشائعة.
- `about.html`، `privacy.html`، `contact.html`: الصفحات القانونية الكاملة باللغة الإنجليزية.
- `sitemap.xml`، `robots.txt`، `ads.txt`، `_headers`: ملفات السيو والأمان والإعلانات.

## خطوة مهمة قبل تفعيل الإعلانات
افتح ملف `data/games.json` وأضف رابط التضمين الرسمي المسموح به في خانة `"embedUrl"` لكل لعبة، ثم غيّر `"status"` من `"coming-soon"` إلى `"ready"` ليعمل إطار اللعبة مباشرة.
